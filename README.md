# Pantheon-Summons

**Summon the gods.** This repo is where every Pantheon god is defined — their SOUL.md, configuration, and divine essence.

```
pantheon-summons/
├── gods/
│   ├── Hermes/       # Pantheon Operations Manager
│   ├── Hephaestus/   # Design & Frontend
│   ├── Apollo/       # Code Generation
│   └── ...           # More to come
├── TEMPLATE_SOUL.md  # Template for new gods
└── README.md
```

## Creating a new god

1. Copy `TEMPLATE_SOUL.md` into `gods/<name>/SOUL.md`
2. Fill in the god's identity, tools, and capabilities
3. Open a PR
